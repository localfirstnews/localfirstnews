## 🛠️ Tools & Resources

### [Subduction](https://github.com/inkandswitch/subduction#readme)
"Subduction is a peer-to-peer synchronization protocol and implementation for CRDTs. It enables efficient synchronization of encrypted, partitioned data between peers without requiring a central server."

### [Tandem](https://tandemsync.dev/)
"Tandem is an open-source sync engine that plugs into your existing infrastructure. Add the Tandem libraries to sync data in real time across your clients and server. No new services to deploy."

### [BackendRelay](https://github.com/orenaksakal/backendrelay)
"BackendRelay is a self-hosted realtime backend: a native Rust server on top of PostgreSQL, a web dashboard, and compatibility with the InstantDB client SDKs. Build apps with relational queries, live subscriptions, optimistic updates, authentication, permission rules, file storage and presence, and run the whole backend on your own infrastructure."

### [ZeBridge](https://github.com/ndrean/ZeBridge#readme)
"ZeBridge keeps a local database on each device, queues writes while it is offline, and synchronizes through NATS when it reconnects. PostgreSQL remains authoritative: it applies the rules, resolves conflicting writes, and returns a verdict to the app."
