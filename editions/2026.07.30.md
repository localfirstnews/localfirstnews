## 🛠️ Tools & Resources

### [ARABA](https://github.com/alistairfontaine/ARABA#readme)
"ARABA is a zero-dependency, offline-first mesh networking protocol built in pure C++17. It turns any Linux device with a Wi-Fi adapter into an encrypted message relay node — no internet, no cell towers, no infrastructure required."

### [Syzy](https://github.com/wjordan/syzy#readme)
"Syzy is a local-first, multi-writer replication system for SQLite. Applications read and write a standard local SQLite file without any network round trip. Syzy replicates committed transactions and resolves concurrent writes so every replica converges on the same result."

### [Agent Island](https://github.com/tristan666666/agent-island#readme)
"See what every run is doing. Step away, and Agent Island calls you back when it is your turn. Local-first, no Agent Island account, no product telemetry."

### [Hydra](https://hydra.uvansa.com/)
"Every other tool is a hosted proxy. We built the local-first one." "Hydra discovers every model on your machine — CLI agents, API keys, local servers — and routes each task to the cheapest head that clears your target confidence"


## ✨ Apps

### [ResearchPocket](https://github.com/ResearchPocket)
"A human-first, local-first library for useful links. Private by default; no account or always-on backend."

### [Kind Local](https://kind.synsira.com/)
"Local-first privacy and control: Your data is stored and analyzed locally by default, and Kind is designed with explicit boundaries and privacy-preserving handling when interacting with external AI services."

### [DrillFlow](https://drillflow.de/en/)
"DrillFlow is a diagram editor where every node can open into its own sub-diagram. Zoom in, understand, come back up — with breadcrumbs instead of tab chaos. Runs locally in your browser."

### [Mumble](https://heymumble.com/dictation)
"Private AI dictation for Mac. Speak into any app with a text field, even offline."

Open CoDesign is the open-source Claude Design alternative — built for people who want the speed of AI-native design tools without subscription lock-in, cloud-only workflows, or being forced onto a single provider. An MIT-licensed desktop app, local-first from day one"
