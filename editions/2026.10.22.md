### [Oxynote](https://github.com/oxynote/oxynote)
Self-hosted, open-source team wiki for runbooks and internal API docs. Live Prometheus and SQL charts run inside the page next to the text, and changes go through a draft with a diff and an approval. v0.9.0 adds variables to live charts. Apache-2.0, one Docker image. _Using Yjs + Hocuspocus for real-time collaborative editing._
