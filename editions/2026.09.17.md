## ✨ Apps

### [VisiGrid](https://visigrid.app/)
A native, keyboard-first spreadsheet built like a code editor, with a command palette, Vim mode, Lua automation, and a CLI for calculating, converting, and diffing spreadsheet data in scripts and CI. Files stay on-device with no account, cloud, or telemetry. _Built in Rust and released under AGPLv3; v0.35 made the desktop app and its previously licensed features free._
